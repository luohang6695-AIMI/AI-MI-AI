# 你给资料，我来操作：安全交接包

你不需要会操作后台。你只需要按下面清单把资料给齐，我负责把资料转成系统输入、每日操作队列和执行动作。

## 1. 不要再发密码到聊天

请不要把账号密码、OTP 手机、个人邮箱密码发到聊天或代码仓库。正确方式：

1. 平台后台给我开子账号。
2. 或者把密码放进密码管理器，再共享指定条目。
3. API token 用最小权限，随时可撤销。
4. 所有高风险动作保留审批：加大预算、改收款、改物流、改价格底线。

## 2. 你只需要给我这些资料

系统清单在 `data/malaysia_operator_intake.csv`：

- 平台权限：Shopee MY、TikTok Shop MY、Lazada MY。
- 产品资料：益生菌 SKU、成本、售价、毛利、变体、主图、视频、详情页。
- 合规资料：益生菌可用宣称、禁用词、标签、证书。
- 库存资料：现货数量、仓库、补货周期、MOQ。
- 预算边界：每日广告上限、每场 Coins 上限、最大亏损容忍。
- 运营资料：销售表、库存表、退款/补发表、日报接收人。

## 3. 我拿到资料后怎么操作

1. 我把资料填进 CSV 输入文件。
2. 我跑 `python3 app/main.py --date YYYY-MM-DD --country MY`。
3. 系统输出马来西亚专属 operator queue 和 growth plan。
4. 我按 `READY_FOR_OPERATOR` 执行。
5. 遇到 `NEEDS_SETUP_OR_APPROVAL`，我只向你要缺的那一项，不让你学复杂后台。
6. 每天复盘 GMV、ROI、库存、退款率，再决定加预算、降预算、补货或停投。

## 4. 销售目标说明

我会按系统目标推进销售，但任何程序或操作者都不能保证收入结果。我们能保证的是：

- 每天有明确动作。
- 每笔预算有 owner、金额和复盘指标。
- 库存、ROI、合规和现金流触发 kill switch。
- 资料越完整，自动化程度越高。
